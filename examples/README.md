| 文件 | 内容 |
|---|---|
| `00-intro.md` | 插件介绍页（hero + 能力卡 + F1–F10 缺陷对照 + 安装命令） |

| `02-dashboard.md` | 监控驾驶舱：LED 状态灯 + 进度条 + Canvas 实时曲线 + 阈值告警联动，「驾驶舱面板」风格 |
